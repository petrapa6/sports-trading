## Manual steps with a demo key (owner)

1. Put a demo key in `kalshi-trader/app/config.local.json` (`kalshiEnv: "demo"`, `kalshiKeyId`,
   `kalshiPrivateKeyPath`).
2. `npm run e2e:demo` — expect the market, order group, order id, `fill_count`, the read-back line, the fee comparison
   and the trade row id. If the fee matches precision 10 000 rather than 100, set the default of
   `fee_balance_precision_micros` in `src/db/settings.ts` accordingly.
3. `npm run dev`, open Trades with mode "live": the row shows `LIVE` and `demo`.
