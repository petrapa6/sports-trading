## Manual steps and observations

### Items 1–2 by hand

```bash
cd kalshi-trader/app
rm -rf .local && DB_PATH=./.local/data/db/trader.db npm run dev &
curl -s localhost:8099/healthz            # {"ok":true}
ls .local/data/db                         # trader.db  trader.db-shm  trader.db-wal
node -e "const D=require('better-sqlite3'); const d=new D('.local/data/db/trader.db');
  console.log(d.pragma('journal_mode',{simple:true}),
  d.prepare(\"select group_concat(name,' ') n from (select name from sqlite_master where type='table' order by name)\").get().n)"
```

Observed: `wal __drizzle_migrations audit_log backtest_trades backtests balance_snapshots bankroll_snapshots
game_snapshots games hist_games hist_prices leagues login_attempts markets sessions settings strategies
strategy_versions teams trade_attempts trades users`. With the `sqlite3` CLI, `.tables` prints the same list.

### Item 7 by hand

```bash
DB_PATH=./.local/data/db/trader.db npm run db:migrate:down   # {"rolledBack":["0001_seed_leagues"],…}
DB_PATH=./.local/data/db/trader.db npm run db:migrate        # {"applied":["0001_seed_leagues"],…}
```

`npm run db:migrate:down -- --all` followed by `npm run db:migrate` drops and recreates everything
(covered by `migrate.test.ts`).

### Item 8 — unwritable directory

- Non-root (the GitHub Actions runner): `test/unit/db/database.test.ts` creates a `chmod 555` directory and
  points the database at it: `/healthz` → `503 {"ok":false,"db":"SQLITE_CANTOPEN"}`. This test is skipped
  when running as root, because root ignores directory permissions.
- Root (this machine): `verify:T02` starts `npm run dev` with `DB_PATH` below a path whose directory
  component is a regular file (unwritable for every user): `/healthz` → `503 {"ok":false,"db":"ENOTDIR"}`.
  The same unit test shows the app recovers (`200`) once the path becomes usable.
- The server still starts when the database cannot be opened (logged at `error`) so `/healthz` can report
  it; a migration failure on an open database exits 1 (SPEC.md T02 implementation notes).
