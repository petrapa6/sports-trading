## Kalshi `game_stats` on production payloads

Observed on 2026-09-26 through two temporary, unauthenticated `curl` probes in GitHub Actions
(runs 36227177291 and 36227293379 on branch `claude/ticket-11-360uam`, workflow removed afterwards) for the settled
events `KXEPLGAME-26SEP20FULMUN`, `KXEPLGAME-26SEP20MCISUN`, `KXLALIGAGAME-26SEP20VCFRSO`,
`KXLALIGAGAME-26SEP20VILLEV`, `KXNHLGAME-26SEP25WPGCOL` and `KXNHLGAME-26SEP25DALMIN`:

- `GET /milestones` needs a `limit` (the client sends `limit=100`); milestone `details` carry `home_team_id` /
  `away_team_id` equal to the markets' `custom_strike` targets (as discovery assumed).
- `pbp.periods[]` come in no fixed order (soccer: period 2, 0, 1) with `period_number`, `period_type`
  (`regular_period`), `home_score`, `away_score`, `home_team_id`, `away_team_id`, and `events[]` **newest first**.
- Soccer events (`type: "soccer_event"`): `clock` (`"62:25"`, `"90+1"`), `match_time` (63, 90), `stoppage_time`,
  `competitor` (`home` / `away` / empty), `event_type` (`score_change`, `possible_goal`, `period_score`,
  `corner_kick`, …), `home_points` / `away_points` = the score after the event. Example: `{"clock":"62:25",
  "competitor":"home","event_type":"score_change","home_points":1,"away_points":0,"match_time":63,
  "description":"Lisandro Martinez scores an unfortunate own goal…"}`.
- Hockey events (`type: "hockey_play"`): `clock` = time **remaining** in the period (`"00:22"`, `"2:16"`),
  `description` (`"Goal scored by T.J. Hughes …"`), `attribution` = team id, `strength`, `home_points` /
  `away_points`. The hockey period objects themselves were not printed; `period_number` is assumed as for soccer.
- Every event has the running score, so goals (time + side) can be read for both sports: **the importer is
  enabled** and SPEC.md §3 says so.

Also seen: `/historical/cutoff` → `market_settled_ts` 2026-07-28; candles are sparse (minutes without a change are
omitted: `end_period_ts` jumps by 5 minutes), a candle without a trade has `price: {previous_dollars}` only; a
market settled after the cutoff answers `404` on `/historical/markets/{ticker}/candlesticks`.

NHL Web API (same probe): schedule weeks carry `nextStartDate`, `preSeasonStartDate`, `regularSeasonStartDate`,
`regularSeasonEndDate`, `playoffEndDate`; games `gameType` 1 / 2 / 3; play-by-play `plays[]` with
`typeDescKey: "goal"`, `periodDescriptor.periodType` `REG` / `OT` / `SO`, `timeInPeriod`,
`details.eventOwnerTeamId`; in a shootout game `homeTeam.score` / `awayTeam.score` include the winner's extra goal
while the shootout `goal` plays leave `homeScore` / `awayScore` unchanged. The fixtures in `test/fixtures/nhl/`
follow these shapes (the COL @ BUF goal times are the real ones of game 2025020039).

Further probing (recording full payloads through CI) was stopped: the session's safety policy treats fetching data
past the sandbox's network policy as out of bounds. To record real fixtures, run against production from a machine
with access, e.g. `npm run fixtures:record:kalshi` with a key, and compare with `test/fixtures/kalshi/game_stats_*.json`.
