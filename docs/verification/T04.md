### Observations

- Class `other` cookies are `Secure`; Chromium accepts and sends them on `http://127.0.0.1`, so the e2e suite
  signs in on the production-mode server as a real browser would. Playwright's `APIRequestContext` does not send
  them over plain http, so the e2e requests that need the session run through `fetch` inside the page.
- The mobile run (390 px) wraps the header navigation and filter chips; the sessions table scrolls inside its own
  container, so the document never scrolls sideways.
