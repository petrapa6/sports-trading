## Manual steps and observations

### Secret hook (item 7), by hand

```bash
git worktree add -b scratch-leak /tmp/wt HEAD && cd /tmp/wt
printf -- '-----BEGIN RSA ''PRIVATE KEY-----\n' > leak.txt   # a bare PEM header
git add leak.txt && git commit -m leak
```

Observed: lefthook runs `secret-scan`; gitleaks reports `leaks found: 1` (rule `private-key-header`) and
the hook prints `secret-scan: gitleaks found a potential secret; commit rejected.`; the commit is not
created. `touch config.local.json foo.db && git status --porcelain` prints nothing. Clean up with
`git worktree remove --force /tmp/wt && git branch -D scratch-leak`.

### Dev server stdout (item 2), by hand

```bash
cd kalshi-trader/app
npm run dev | tee /tmp/dev.out &
curl -s localhost:8099/healthz        # {"ok":true}
jq -e . /tmp/dev.out >/dev/null && echo all-json
```

Observed: `{"ok":true}`, `all-json`. npm's own `> kalshi-trader@0.1.0 dev` banner is suppressed by
`kalshi-trader/app/.npmrc` (`loglevel=silent`).
